# slice1-observation-core：切片一"证明读得准"

日期 2026-10-30　状态 SPEC_DRAFT（待用户确认 UI Demo 与规格后启动实施）

上位方案：[整体产品方案 v0.1](../../docs/SentiScope_整体产品方案_v0.1.md) §7 变更 1。本变更建立最小可运行宿主与确定性观察管道，证明"读得准、拦得住"，不投递 Case。

## 完整可观察结果

1. **宿主可启动停止**：以双击入口（或等价命令）启动阶段 1 形态宿主（非常驻、可开关），完成 pi-coding-agent headless 会话的创建、工具注册、事件订阅与正常结束（会话探针，合成任务）。真实模型调用不作为本变更门禁；如实施中执行，须单独授权并记录。
2. **skill 加载可验证**：至少一个能力 skill（建议：口径校验 skill）按官方 SKILL.md 规范放入 skills/ 并被宿主发现与加载，加载结果有日志证据。
3. **合成 BI 模拟源**：本地 fixture 服务（进程内或 loopback），按只读适配器接口提供驾驶舱样数据与快照，可注入各类口径异常（过期、单位不一致、零分母、筛选漂移、字段不清）供样例复用。
4. **配置模型**：来源与规则配置按整体方案 §3 字段全量落地（含规则身份与版本），声明式文件加载，错误配置被拒绝并给出原因。
5. **口径校验管道（确定性代码）**：可比性链（实体/周期/单位/过滤/刷新/已结期与轨迹）→ 方向与零分母规则 → 差额计算 → 触发判定，输出四态：正常 / 合格差距 / 证据不足 / 采集失败；每个环节的结果与原因逐项留痕。
6. **证据快照**：不可变落盘、SHA-256、来源定位（字段路径/偏移）、双时间戳（业务刷新/抓取）；快照只追加。
7. **观察存储**：观察记录（四态、校验链结果、证据引用、稳定观察身份）持久化且可查询；append-only。
8. **管理界面（只读）**：按已确认 UI Demo 实现观察总览、运行记录（含状态与原因）、证据下钻、来源与规则查看；投递状态区占位标注"切片二启用"。
9. **Agent 疑点补读（最小循环）**：疑点触发时经授权工具补读或重取一次证据的循环可演示；预算与停止行为明确；不确定时留未知项。真实模型调用须授权，CI 只覆盖确定性管道。

## 需求/验收标识

源自[产品讨论稿 v0.1](../../../OptraCall_自主探索Agent_产品讨论稿_v0.1.md) §7 合成样例表，本变更覆盖读取与校验类：

| 标识 | 样例 | 预期行为 |
| --- | --- | --- |
| OBS-01 | 正常达标 | 状态"正常"，不产生差距记录，不创建任何投递动作 |
| OBS-02 | 明确越界（已结期、超阈值） | 一条"合格差距"观察：业务事实、规则身份与版本、证据引用齐备；不投递（切片二边界） |
| OBS-03 | 数据过期或延迟刷新 | "证据不足（数据质量）"，等待有效刷新，不当作经营差距 |
| OBS-04 | 单位或周期不一致 | 拒绝比较，记录缺失口径项，不生成误导性差距 |
| OBS-05 | 未结期且无目标轨迹 | 不判不达标、不生成期末风险预测；记录现状观察 |
| OBS-06 | 越低越好与零分母 | 按配置方向判定；零分母不除零、不产生伪达成率 |
| OBS-07 | 筛选漂移或字段不清 | 检测到范围变化/数字不确定即暂停比较，保留待核实记录 |

每条样例同时断言：状态、原因、证据引用与时间戳完整；未产生 Case/Project/投递副作用；重复执行同一输入结果一致（可重复验证）。

## 范围与不做

不做：连接真实 BI 或任何外部业务系统；Case 投递、队列与 OptraCall 侧改动；自动建 Project；预测模型；第二类发现（无预设目标的问题与机会）；自动学习闭环；常驻部署；cron 级调度器（本变更用最简触发：手动/定时器）。

## 关键边界

- 数据唯一来源为本地合成 fixture；无真实凭据；除单独授权的模型调用外无网络出口。
- 观察记录 append-only；证据快照不可变；不因重试或文案变化制造新观察身份。
- 宿主不控制 Agent 步骤：Agent 循环仅以工具、预算与输出格式约束，不写死分析状态机。
- 不重复造轮子：会话、工具、skill、事件、codemode 均用 pi-coding-agent 官方件。
- 本变更通过不等于切片一验收：须独立复核与用户对固定候选的适用验收。

## 适用检查

- `node --test`：OBS-01～07 端到端样例 + 管道单元（校验链、方向/零分母、快照哈希、观察身份稳定）+ 配置校验
