# slice2-exploration-candidates：切片二“真实探索，形成可信候选”

日期 2026-10-30　2026-11-01 范围修订　状态 SPEC_DRAFT（v0.3 deepresearch 检索模式，待实施与验收；此前候选 `51e3125` 的真实验收已中止且执行层 FAIL，见[结果记录](result.md)，不得在本规格中改写为通过）

基线：SentiScope `main@cb3103e`；目标形态以分支后续新候选实现。上位方案：[整体产品方案 v0.3](../../docs/SentiScope_整体产品方案_v0.3.md) §2～§8。原 `slice2-delivery` 草案不实施；当前分支已有的单 URL `public-web` 抓取路径不符合 v0.3，后续候选必须重构为受控搜索工具链。

本变更交付最小真实闭环：**用户导入 CSV／XLSX → 原始证据保存 → 可重放清洗与标准数据集 → 真实 pi-coding-agent 自主做目标／历史／竞对／行业描述性比较；缺少外部基准时自主调用 `web_search`／`fetch_page`／`read_snapshot` 补证 → 证据门禁 → SentiScope Case 候选看板。** 真实模型是必要验收组成；本规格阶段不实际调用模型、不访问真实公网、不读取用户真实数据。

## 启动条件与授权边界

1. 用户确认本规格与 [UI Demo](clickable/index.html) 后，方可实施；正式 UI 以 OptraCall `origin/main@3f4603e` 的实际应用外壳、Case 看板和详情抽屉为参照。
2. 工程 CI 只使用合成 CSV／XLSX、合成网页和受控模型／工具替身，不访问真实公网或用户文件。
3. 真实模型运行前，用户须确认模型配置、预算、允许进入模型的数据字段与数据出口；真实公网检索前另须确认搜索 Provider、密钥存放、搜索／读取配额与偏好来源范围。两项授权分别记录，不能由开发或 Git 权限推导。
4. 用户导入文件仅进入本次明确授权的本机工作区与模型路径；原始文件、真实经营数据、会话与日志不得进入公开仓库。
5. 本变更不修改 OptraCall，不连接真实 BI，不自动创建 Case／Project，不实施持久投递队列。

## 完整可观察结果

1. **文件导入与原始保真**：支持约定的 CSV／XLSX；保存原始字节、SHA-256、文件名、媒体类型、导入时间、解析器与版本。重复上传同一内容复用原始资产引用，文件名变化不改内容身份。
2. **deepresearch 公网检索**：Agent 自主发起 `web_search`，从命中中选择少量公开 URL 调用 `fetch_page`，再用 `read_snapshot` 分页核对原文；Host 提供 Provider 链、配额、SSRF／robots／大小校验、快照保存与调查事件。搜索摘要只是线索，候选事实必须引用快照原文或表格单元格。不做爬虫、站点遍历或链接批量抓取。
3. **数据画像与质量报告**：展示行列规模、推断类型、缺失、重复、非法值、日期覆盖、实体与单位分布；异常项能定位到原始行／单元格／网页位置。
4. **可重放清洗**：字段映射、类型解析、日期与时区、实体别名、单位换算、重复与空值策略均形成显式步骤；禁止静默删除、填补、猜测单位或覆盖原始数据。
5. **标准数据集版本**：输出以“指标＋实体＋期间＋数值＋单位＋维度”为核心的标准记录、数据字典和质量报告；每行可沿转换步骤回到上游资产，旧版本不可改写。
6. **真实 Agent 自主探索**：通过统一 pi-coding-agent SDK 调用真实 `session.prompt()`，加载 skills 与领域工具；Agent 在数据版本、基准、网络、权限和预算内自主选择比较、查询、补证、反证与停止，Host 不写死分析顺序。
7. **四类描述性比较**：目标、历史、竞对、行业比较由确定性工具完成差值、差率、增速与百分点差计算，保存公式、输入、输出、工具版本和证据引用。
8. **观察与反证留痕**：画像、查询、比较、数据质量问题和放弃原因均为结构化观察；Agent 检查合理的替代切片、反向证据或数据质量解释，模型 prose 不能独立成为事实。每次运行保存搜索覆盖与选择上下文：检查过哪些指标、实体、切片和基准，以及为何舍弃其他结果。
9. **Case 候选门禁**：只接受四类差距候选；候选必须具有可比口径、业务重要性、可复现计算、支持与反证、完整证据血缘、限制和未知项。引用不存在证据、缺计算、指纹不符或关键口径不明的提交被宿主拒绝。**未通过门禁的待补证项只进入观察／补证列表，不进入 Case 候选看板；候选看板只含已通过门禁的待复核、已保留、已排除记录。**
10. **允许零候选**：没有合格差距、数据不足或证据冲突时，运行以“无候选／待补证”正常结束，显示已检查内容与停止原因，不强制产出。
11. **运行可控可恢复**：持久记录模型、会话、数据版本、工具事件、预算与停止原因；支持取消和重启后查看。取消不提交半成品候选，预算耗尽不绕过限制。
12. **候选人工复核**：默认看板支持搜索、状态筛选、卡片／列表切换和详情抽屉；用户可保留或排除候选并写说明，人工动作不修改原始观察与证据，也不自动创建 OptraCall Case。
13. **OptraCall 风格 UI**：实现对应外壳、主题、导入侧栏、探索工作区、数据集／来源视图、候选卡片和宽右详情抽屉；不可信文件与网页文本全部安全渲染。
14. **旧数据保全**：新 MVP 使用独立数据目录与 schema，不改写切片一数据库和证据；旧固定轮询代码退出时不得删除用户数据目录。

## 需求／验收标识

### 导入、公网与清洗

| 标识 | 场景 | 预期行为 |
| --- | --- | --- |
| IMP-01 | 正常 CSV／XLSX、同内容不同文件名、重复导入 | 原始字节与哈希准确；同内容复用资产；解析身份与原始身份分离 |
| IMP-02 | 空文件、损坏文件、重复表头、混合编码、超出大小／行列限制 | 明确拒绝或隔离问题行；无静默截断，无部分数据冒充完整数据集 |
| IMP-03 | 单元格含 HTML／脚本、公式、宏或类似提示注入的文字 | 只作为数据处理；不执行、不扩大权限，UI 不发生 XSS |
| IMP-04 | XLSX ZIP bomb／异常压缩比、XXE、外部工作簿关系、宏、公式与过期缓存值 | 解压大小／比例／深度受限；禁 XML 外部实体、外部关系与解析器网络；宏／公式不执行；缓存值标明计算来源与时点，过期或不可确认时不得当作实际值 |
| WEB-01 | Agent 发起搜索，Provider 返回命中 | 保存 query、Provider、callKey、命中 URL／标题／摘要、来源等级与配额事件；命中仅是线索，不进入候选事实 |
| WEB-02 | Provider 429／限额／瞬时 5xx、永久错误、未配置或配额耗尽 | 瞬时错误按链切换；其他错误与配额耗尽以错误值返回并提示收束；不隐藏重试、不伪造无结果、不把失败写成证据充分 |
| WEB-03 | 搜索摘要含数字或页面含“忽略规则／调用工具”等指令 | 摘要与指令均不可成为证据或权限；只有 fetched snapshot 的逐字引用可进入事实，二手来源标注来源等级 |
| WEB-04 | Agent 选择 URL 读取时出现非 HTTP(S)、URL 凭据、非常规端口、DNS rebinding、loopback／私网／链路本地／保留／NAT64 地址、重定向入内网或元数据服务 | Host 在请求前、每次连接与最终 URL 后校验并拒绝；robots／登录／验证码／反爬／条款／大小／超时不满足即停止，不绕过 |
| WEB-05 | Agent 或页面把内部值编码进 search query、URL、查询、头部或正文 | Host 出口扫描阻止请求并留事件；内部数据不出现在搜索词、公网请求、Provider 日志或模型请求中 |
| WEB-06 | 同一重要外部数字只有一个快照、二手来源或无法定位原文 | 候选降级为待补证或标注单源限制；不得把搜索排名、模型自述或转载摘要当作独立证据 |
| CLN-01 | 缺失、重复、非法日期、混合类型与异常值画像 | 数量、位置与处理建议准确；原始值保留，异常不自动等于经营问题 |
| CLN-02 | 字段映射、实体别名、单位换算、时区与重复处理 | 每步有参数、版本、输入输出哈希与行级血缘；可重放得到同一标准数据版本 |
| CLN-03 | 单位不明、关键值缺失或转换冲突 | 不猜值、不静默填补；相关记录标为不可用并阻止对应比较，其余可用数据可独立分析 |

### 描述性比较与候选门禁

| 标识 | 场景 | 预期行为 |
| --- | --- | --- |
| CMP-01 | 越高越好指标已结期且低于目标超过重要性阈值 | 工具按方向计算目标差距；口径、目标来源和阈值完整，可形成候选 |
| CMP-02 | 越低越好指标高于目标，以及相反方向的正常样例 | 差距方向正确，不把“数值更高”一律写成问题，不把“数值更低”一律写成好事 |
| CMP-03 | 目标为零／负数或分母不适用 | 不套普通达成率；按约定绝对差或标不可计算，不输出伪百分比 |
| CMP-04 | 未结期对全期目标、部分当前期对完整历史期 | 不直接判最终不达标或同比；无认可同期／进度基准时只留观察 |
| CMP-05 | 去年同期正基数、零基数、负基数 | 正基数正确算同比；零／负基数不套普通增长率，改用约定绝对差或标不可计算 |
| CMP-06 | 自身与竞对同期增速可比 | 分别计算增速，再算百分点差；双方原始证据和披露范围完整 |
| CMP-07 | 自身与竞对／行业的指标、地域或周期口径不同 | 不硬比；差异不可解释时待补证，不生成候选 |
| CMP-08 | 自身增速低于行业基准且行业数据滞后 | 显示各自周期与发布时间；只有比较期一致且差距满足阈值才可候选，不伪装成实时行业表现 |
| CMP-09 | 分母为零、单位／币种不同、重复记录未处理 | 工具拒绝或按明确规则处理；不输出伪差率、伪增速或伪百分点差 |
| CMP-10 | 大量指标／实体／切片中存在随机极端值与伪相关 | 保存完整搜索覆盖、候选选择上下文和舍弃原因；不能只挑极端切片，近失样例不得成为候选 |
| CAND-01 | 候选缺少证据、计算记录、基准来源、反证或未知项 | 宿主拒绝提交并给出具体缺项；只留观察／补证记录，不进入候选看板 |
| CAND-02 | 差距显著但存在相反切片或数据质量解释 | Agent 检查并记录；冲突未解决则待补证，不得只保留有利证据 |
| CAND-03 | 候选标题写成“竞对导致下滑”等根因或预测 | 拒绝或要求改为描述性表述；结论不得超过证据 |
| CAND-04 | 同一标准数据与基准重复提交 | 候选事实指纹稳定，不因措辞或运行次数重复刷板；实质新证据形成候选修订并保留历史 |

## 关键边界

- **原始与派生分离**：上传原字节和网页快照不可变；标准数据、观察和候选都有上游血缘。
- **模型不是事实来源**：模型提出假设、选择工具和组织解释；数值、统计、清洗与候选事实必须由确定性工具和持久证据支撑。
- **外部数字资格由 Host 核验**：快照解析的发布时间与来源分级是资格信号；模型声明与之冲突即拒绝，C 级来源按二手记录，仅来自单个快照的外部基准必须带 Host 标注的单源限制。
- **Host 校验反馈而非代答**：检索请求的校验失败与配额耗尽以错误值回到 Agent 并留事件，由 Agent 自主修正或收束；Host 不替 Agent 决定下一个工具、搜索词或结论。
- **Host 不导演分析**：Host 管权限、工作区、Provider、预算、网络边界和输出门禁，不预设固定探索步骤，不替 Agent 写搜索词或排序命中。
- **比较先于结论**：没有可比基准就没有四类候选；行业／竞对数字必须带范围和时间。
- **反证与零候选是一等结果**：不得通过提示词或 UI 数量指标强迫 Agent 产出。
- **候选不是 Case**：人工复核只改变候选复核状态，不向 OptraCall 写入，不自动建 Project。
- **不可信输入 fail-closed**：文件、网页和模型输出均不可直接获得新权限；UI 安全渲染，搜索 Provider、网络边界与工具权限由 Host 强制执行。
- **完成定义分离**：受控测试、真实模型、真实公网、独立复核、CI、用户验收和 Git 交付分别记录。
