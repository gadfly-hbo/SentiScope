# slice3-candidate-trial：切片三"候选试用与校准"

状态：草案，待用户审核后实施。上位方案：[整体产品方案 v0.3 §8](../../docs/SentiScope_整体产品方案_v0.3.md)。

## 目标与启动条件

- 前置：切片二已合并 main（PR #2，`7d9ad0c`）；真实模型（`minimax-cn:MiniMax-M3.1-Flash`）与真实搜索 Provider（MiniMax Coding Plan）验收通过；held-out 与稳定性通过。用户已裁定：合成数据通过即真实通过，导入链路不再单独测试。
- 目标：支撑**多组数据的连续试用**，把人工复核反馈、阈值与来源质量校准、模型与工具成本观察沉淀为可审计的试用台账，最终产出试用结论——候选命中率、证据质量、成本是否达到进入切片四（OptraCall 投递）或扩来源的标准。
- 授权边界：工程验证继续用合成 fixture；试用期的真实数据由用户自行导入本机数据目录，不入仓库、不入日志，数据出口沿用切片二边界（行投影白名单、禁止外发值、快照逐字引用）。真实模型与搜索沿用已授权配置，不新增授权面。

## 完整可观察结果（试用台账）

1. **基准阈值版本化**：`benchmarks.ts` 内置定义迁移为"代码默认＋数据目录 `benchmarks.json` 用户批准覆盖"，每次变更记录版本号与理由；运行与候选继续引用 `thresholdVersion`，历史候选不因配置变更被改写。
2. **多数据集运行**：启动运行时可指定数据集（默认最新导入）；运行、观察、候选、搜索事件全部绑定所选数据集，切换数据集不破坏历史，看板可按数据集过滤。
3. **反馈统计**：候选排除新增结构化原因标签（口径不符／证据不足／重复／其他，复选其一，说明仍可选）；按运行、数据集、比较类型汇总 review/retained/excluded 与原因分布；复核历史只追加。
4. **成本观察**：每轮运行结束从 Pi 会话记录（SDK 自身持久化，Host 只读自身数据目录）与 Host 事件读取 token 用量／费用（可得时）、模型调用、搜索／抓取／快照读取次数，写入运行记录并累计展示；不重建遥测流（延续 B-08）。
5. **试用报告**：本机生成 Markdown 报告：候选命中率与排除原因分布、证据质量抽查清单（抽样候选回链快照原文）、成本汇总、阈值与来源配置的当前版本及历次变更；报告只陈述统计与建议清单，不自动改任何配置。

## 需求／验收标识

### 配置与校准

| 标识 | 场景 | 通过标准 |
| --- | --- | --- |
| TRI-01 | `benchmarks.json` 缺失／字段非法／阈值越界 | 缺失时回落代码默认并在启动日志标明；非法即启动失败（fail-closed），不静默用错值；合法覆盖记录版本与时间 |
| TRI-02 | 试用期修改某基准阈值 | 生成新 `thresholdVersion` 并留变更记录；已存在候选的 `thresholdVersion` 与比较结果不变；新运行用新版本 |
| TRI-03 | Agent 或运行期请求改阈值／来源配置 | 拒绝；配置只能由用户在数据目录修改并重启生效（Host 不提供运行期写配置接口） |

### 试用运行与统计

| 标识 | 场景 | 通过标准 |
| --- | --- | --- |
| TRI-04 | 指定历史数据集启动运行 | 运行绑定该数据集版本，候选与搜索事件同源；不指向最新导入也可运行 |
| TRI-05 | 排除候选时不选原因标签／选多项 | 必选且单选，缺省拒绝；标签与说明一起进入复核历史与统计 |
| TRI-06 | 多轮运行后查看统计 | 按数据集／比较类型／运行给出 review-retained-excluded 计数与排除原因分布，数值可回溯到具体候选 |
| TRI-07 | 运行结束后查看成本 | token／费用（会话记录可得时）、模型调用次数、搜索／抓取／读取次数随运行持久化；会话无费用字段时如实标注"不可得"，不估算冒充 |

### 报告与边界

| 标识 | 场景 | 通过标准 |
| --- | --- | --- |
| TRI-08 | 生成试用报告 | 只含统计、抽查清单与建议列表；不修改配置、不外发、不含用户原始数据内容 |
| TRI-09 | 报告中的证据抽查 | 每个抽样候选可回链标准行、快照原文窗口或计算事件；回链失败在报告中如实列出 |
| SEC-01 | 配置文件包含内部值或异常结构 | 校验拒绝并给出字段级错误；不进入模型、不写入日志正文 |

## 管理界面验收（对应试用视图）

- UI-09 试用视图：运行历史（数据集、模型、候选数、成本）列表与筛选；统计卡片（命中率、排除原因分布）。
- UI-10 配置状态：当前 `benchmarks.json` 版本、生效阈值与最近变更记录展示；运行期无修改入口。
- UI-11 报告入口：本机下载 Markdown 报告；页面标注"统计与建议，不自动生效"。

## 范围与不做

- **范围内**：阈值与来源配置版本化、多数据集运行选择、排除原因标签与统计、成本观察、试用报告、对应 UI 与测试。
- **不做**：OptraCall 投递（切片四）、真实 BI／定时刷新／来源扩展（未排期）、自动调参（任何阈值变更都由用户批准）、常驻／跨机部署、把用户真实数据写入仓库或日志。

## 允许修改路径

- `src/core/benchmarks.ts`（默认定义＋配置加载与版本记录）、`src/core/workspace-store.ts`（配置版本表、运行成本字段、原因标签）、`src/host/server.ts`（数据集选择、统计与报告 API）、`src/ui/*`（试用视图）、`tests/*`（TRI／SEC 用例）。
- 不修改 Agent 工具语义与候选门禁判定逻辑本身；`thresholdVersion` 语义不变。

## 关键边界

- **校准是用户批准的配置变更，不是 Agent 行为**：Host 提供统计与建议清单，绝不自动调整阈值、来源分级或配额（延续 B-03、B-06）。
- **成本读取不重建遥测**：只读 SDK 会话持久化与 Host 自身事件，不订阅、不复制、不折叠 Agent 遥测（延续 B-08）。
- **试用数据留在本机**：用户导入的原始文件与派生数据只在数据目录；仓库、报告样例与测试全部使用合成数据。
- **报告不外发**：生成与下载均在本机，不调用任何外部服务。

## 适用检查

- `node --test`：TRI-01～09、SEC-01 全量；配置非法矩阵、版本不变性（历史候选不受新阈值影响）、数据集绑定、统计正确性、成本缺失降级、报告内容边界。
- 受控路径（合成数据）验证全部工程行为；真实模型／搜索沿用切片二授权，仅在试用会话中使用。
- 浏览器验证 UI-09～11（桌面、窄屏、明暗主题）；不可信文本渲染用例沿用。
- 非作者独立复核；工程规范 §4 Host 与 Agent 职责边界及复用检查作为合并前最终验收；CI 通过后 squash 合并 main。

## 未决问题（实施前确认）

1. 排除原因标签集合是否按"口径不符／证据不足／重复／其他"四类固定，还是允许用户自定义枚举（当前方案：固定四类）。
2. 成本中"费用"字段若 Pi 会话记录不含金额，是否只报 token 与次数（当前方案：只报可得项并标注）。
3. `benchmarks.json` 是否同时承载来源分级偏好（`preferredDomains` 合并进同一配置文件，或维持 `search.json` 分离；当前方案：维持分离，避免一次变更两处语义）。
