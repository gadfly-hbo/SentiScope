# slice4-source-expansion：切片四"来源与比较维度扩展"

状态：草案，待用户审核后实施。上位方案：[整体产品方案 v0.3 §8](../../docs/SentiScope_整体产品方案_v0.3.md)（"后续来源扩展"项，原切片四 OptraCall 投递由用户决定顺延）。

## 目标与证据依据

- 用户决定：进入来源扩展，OptraCall 投递（原切片四）后置。
- 切片二/三真实运行证据（见 [slice2 result.md](../slice2-exploration-candidates/result.md)）：
  1. 高价值来源常为 PDF（统计机构季报、上市公司披露），当前 `fetch_page` 对 `application/pdf` 一律 `content_type_rejected`，Agent 只能放弃或降待补证；
  2. MiniMax 搜索命中以 C 级转载/新闻为主，一手统计页（HTML）偶有命中（stats.gov）但覆盖窄；
  3. Agent 曾尝试"环比"与"同级区域对比"表达，Host 无对应基准定义，只能拒绝或硬套同比。
- 目标：把"能用的来源"扩到 PDF 文本层、把"能表达的比较"扩到环比（上一期）与同级实体对比；继续不做爬虫、不做站点遍历、不自动投递。

## 范围与不做

- **范围内**：PDF 快照（受限文本层解析）与逐字引用；环比基准定义（上一期）；同级实体对比基准定义（可选，见未决问题）；对应清洗/比较/测试与必要 UI 标签。
- **不做**：真实 BI 连接、定时刷新（阶段 1 非常驻）、新爬虫/批量抓取、OptraCall 投递、更换搜索 Provider（仍 MiniMax Coding Plan，链式配置已支持多家，用户要加再加）。

## 需求／验收标识

### PDF 来源（SRC）

| 标识 | 场景 | 通过标准 |
| --- | --- | --- |
| SRC-01 | Agent `fetch_page` 命中 `application/pdf` | 受限解析文本层并保存快照（content-type、页数、字符数入记录）；不执行脚本、不加载外部资源、超大小/页数/无文本层（扫描件）fail-closed 为错误值并留事件 |
| SRC-02 | PDF 快照的 `read_snapshot`／`record_web_fact` | 与 HTML 同一逐字引用校验（quote 必须在文本层、valueText 在 quote 内）；引用窗口标注页码与字符偏移 |
| SRC-03 | PDF 解析依赖 | 许可证、安全审计、文件大小/页数/解压边界审查通过后引入（候选 unpdf／pdf.js 系）；依赖清单与审计结果记录于 result.md |
| SRC-04 | 恶意/异常 PDF（嵌 JS、超大、加密、损坏） | 一律拒绝或降级错误值，不崩溃、不执行、不留部分写入 |

### 比较维度（CMP2）

| 标识 | 场景 | 通过标准 |
| --- | --- | --- |
| CMP2-01 | 环比（上一期）基准定义（如 revenue-mom：2026-09 vs 2026-08） | Host 批准的定义（方向、阈值、版本化）；期间校验为"紧邻上一期"（月对月、季对季），数据缺上一期时 fail-closed 待补证 |
| CMP2-02 | 同级实体对比（如 华东 vs 华南，同指标同期间同单位）——**可选，未决问题 1** | Host 批准的泛化定义：actual/benchmark 实体可变但必须同 metric、同 unit、同期间、双方 usable；实体相同或口径不一致拒绝 |
| CMP2-03 | 新比较类型的候选与 UI | 候选走同一门禁（证据、反证、覆盖、单源限制）；看板类型标签与统计分组同步扩展 |

- **按流程：涉及 UI 变更，实施前出可点击 Demo 交用户审核（若用户认为变更是纯标签级可豁免，请在审核 spec 时说明）。**

## 关键边界

- PDF 解析是确定性文本提取，属 Host 环境能力；不新增任何模型可调用的"解析选项"，Agent 仍只有 `fetch_page`/`read_snapshot`/`record_web_fact` 三个工具。
- 新基准定义仍为 Host 批准的业务上下文（含阈值与版本化，纳入 `benchmarks.json` 可覆盖范围）；Agent 不得自创定义或阈值。同级对比沿用 sharedScope（scope／currency／region 口径一致）：跨地域区域对比需数据建模上统一 region 口径才可成立，否则如实待补证。
- 来源等级与发布时间交叉核验规则不变（publishedAt 冲突拒绝、C 级按二手、单源限制标注）；PDF 来源按域名分级同理。
- 不为"扩来源"放松出口扫描、robots、SSRF、大小与配额边界。

## 适用检查

- `node --test`：SRC-01～04（含恶意 PDF 矩阵）、CMP2-01～03 全量；PDF 文本层与引用窗口的单元与宿主级用例；环比/同级定义的期间与口径矩阵。
- 依赖审查：新 PDF 依赖的许可证、`npm audit`、解压/大小边界。
- 受控演示：fixture 增加一份合成 PDF 披露（含可引用文本）与环比数据行，演示走通 fetch→read→record→compare→候选。
- 浏览器验证来源卡片与看板标签；非作者独立复核；工程规范 §4 边界检查；CI 后 squash 合并 main。

## 未决问题（实施前确认）

1. **同级实体对比是否纳入本切片**（CMP2-02）：真实运行中 Agent 曾想表达"华东 vs 华南"，但该定义把"谁和谁比"的决定权部分交给 Agent（Host 只校验口径一致）。建议：纳入但阈值从严（如差距阈值高于同比），且 selectionContext 必须说明选择理由；也可后置。
2. PDF 依赖选型：倾向 `unpdf`（MIT/Apache-2.0，pdf.js 系，无原生编译），审查通过后引入；如有偏好请指定。
3. 环比期间粒度：仅支持"月对月、季对季"两种紧邻上一期，还是也允许"周对周"？（建议：先月/季，周后置。）
